PHOTOS FOR THE HOME PAGE
========================

Put your photos in this folder using EXACTLY these file names.
The site picks them up automatically. No code change is needed.

  shaniwar-wada.jpg     Big banner under the search box. Landscape, about 1600 x 900.
  aga-khan-palace.jpg   Gallery card. Landscape, about 1200 x 800.
  fc-road.jpg           Gallery card. Landscape, about 1200 x 800.
  pune-metro.jpg        Gallery card. Landscape, about 1200 x 800.

Tips
- Use JPG. Keep each file under about 300 KB so the page loads fast.
  The free tool https://squoosh.app shrinks photos without visible loss.
- Use photos you took or have the right to use. Do not copy images from
  Google results or other websites.
- Until a photo is added, a clean coloured placeholder is shown instead.
- After adding a file, refresh the page. If it still shows the placeholder,
  check the file name and that it ends in .jpg (not .jpeg or .JPG).
